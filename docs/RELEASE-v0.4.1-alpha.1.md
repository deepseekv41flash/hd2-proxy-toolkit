# v0.4.1-alpha.1 — 物品解锁：一键清空全部已添加项（批量移除库存/目录追加）（2026-11-18）

> **alpha 预览版 · 小幅功能扩展**：patch 位变化（`0.4.0-alpha.1` → **`0.4.1-alpha.1`**）。

## 背景

物品解锁页支持批量**添加**：附件 tab 一级选武器 + 「添加到库存」= 一次解锁该武器全部配件
（附件是「武器 × 附件」粒度，最多 1455 条）。但**移除只能逐条点**右侧表格的「删除选中」——
附件一把枪几十条，想要撤回整把枪的配件得点几十次；也没有「全部撤回」的入口。

## 新增：顶部「清空全部已添加」按钮

物品与战备页顶部汇总行右侧新增红色按钮 **「清空全部已添加」**（danger），一次撤回本页所有改动：

| 清掉 | 说明 |
|---|---|
| 武器 / 附件 / 外观 / 战备 四类库存行 | `profile["inventory"][key]` 全部清空（库存行 = 解锁/试用） |
| 目录追加列表 | `profile["items"]["add"]` 清空；「目录缺失物品」自动配对的目录行随之消失 |
| 保留 | `profile["items"]["template"]` 这类标量设置、以及 profile 的其它页数据 |

交互细节：

- 点击先弹**确认框**，列出各类条数（例：`确定移除本页所有已添加项？` / `武器 0 · 附件 117 · 外观 1 · 战备 0 · 目录追加 1`）；
  **点「否」不做任何改动**；
- 本页没有可清项时直接提示「本页没有已添加项（库存与目录追加都是空的）」，不弹确认框；
- 只改本机内存 profile，点右上角「应用配置」后才热更新到引擎（与其它编辑操作一致），
  「保存配置」才落盘。

## 验证

- 单测 **468 → 470**：
  - 批量添加一把武器的全部配件 + 加一条武器 + 目录追一条 → 点「否」全部保留；点「是」四类库存行与
    目录追加全部清空、`template` 保留、汇总行归零、toast 报数（端到端断言）；
  - 空列表时点按钮：明确提示、不弹框、不标脏。
- `python tools/check_gate.py` → **GATE=PASS**。
- 打包版实机（临时 state 隔离用户 profile）：附件 tab 一级选武器 → 批量添加 → 顶部「清空全部已添加」→
  确认框列出条数 → 点「是」→ 汇总「已加入：附件 0」、列表清空；点「否」路径再次验证无改动。

## 升级提示

覆盖安装即可（配置与证书在 `%LOCALAPPDATA%\HD2ProxyStudio`，不受影响；profile 格式未变）。
升级后打开「物品与战备」页即可看到顶部新增的「清空全部已添加」按钮。

## 已知限制（alpha）

- 本版只做「全部清空」：暂不支持「只清某一类」「只清某把武器的配件」「只清列表里多选的行」——
  单项删除仍用各 tab「删除选中」（后续版本可按需加按类/按武器批量移除）；
- 引擎侧上游偶发超时（多 IP 重试）仍是待办，未包含在本版。

# v0.4.3-alpha.1 — GUI 新增「实时战况」页（免游戏拉取 + 排查视图）（2026-11-20）

> **功能版本**：`X.Y.Z` 变化（`0.4.2-alpha.1` → **`0.4.3-alpha.1`**）。

## 背景

`0.4.2-alpha.1` 已经能从命令行（`hd2proxy live`）免游戏拉官方战况。但排查「卡面为什么不显示」
时，命令行输出不够直观：要看**这颗星有没有战役（可点）**、**它到底挂了哪些 effect**。
这一版把同一份数据做成 GUI 的一个独立页面。

## 新页面：实时战况

侧栏第 3 项（`◉` 实时战况），不启动游戏、不启动引擎也能用（数据直连官方公共只读 API）：

| 区域 | 内容 |
|---|---|
| 工具条 | **拉取战况** / 保存快照 / 打开快照目录 / **自动刷新**（默认关，15–600 s）/ 上次拉取状态 |
| 摘要卡 | 战局（warId · status time）、星球/战役、星球效果数、GWE 目录条数（附出口 IP、耗时） |
| 左表「靶星」 | 有战役的星球（**卡面可点**）：阵营 / 星球 / 索引 / 战役 id，前线优先 |
| 右表「星球效果」 | `planetActiveEffects` 按星球聚合：星球 / effect ids / 数量；可按星球名/索引/effect id 过滤；选中一行看 `id · 名称` |
| 快照 | 每次拉取自动存 `%LOCALAPPDATA%\HD2ProxyStudio\live\last\`；「保存快照」另存带时间戳目录 |

截图：[`research/screenshots/live-page-20261120.png`](../research/screenshots/live-page-20261120.png)
（2026-11-20 实拉：war 801 / 273 星球 / 41 战役 / 166 条星球效果 / GWE 315 条）。

## 排查用法（把「靠猜」变成一屏可见）

1. 卡面看不到目标星的词条/变种 → 打开「实时战况」→ 点「拉取战况」；
2. 看**左表**：目标星在不在？不在 ⇒ 它本季没有战役、卡面不可点（换一颗有战役的星）；
3. 在左表 ⇒ 看**右表**：找到目标星，确认它挂了哪些 effect；点行看每个 effect 的名称；
4. 对照 profile（战况改写页）里注入的 `planet_effects`，就能判断「是没注入 / 注入到别处 / 客户端没显示」。

## 实现要点

- 复用 `engine/live.py`（DoH 解析真实 IP → SNI 直连，正常证书校验；只读 GET、8 MiB 上限、15 s 超时）；
- 拉取在后台线程（`app.run_bg`），GUI 不卡；自动刷新只在「实时战况」页处于激活状态时触发；
- 星球/效果名称来自本地目录（`data/catalogs/planets.json` / `effects.json`），离线也能显示；
- 页面注册进 `PAGE_DEFS`；`tools/gui_smoke.py` 冒烟页数 5 → 6。

## 测试与验收

## 兼容性

- 无数据/profile/控制面协议变化；`0.4.2-alpha.1` 的 `hd2proxy live` 行为不变；

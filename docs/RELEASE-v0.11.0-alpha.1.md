>

## 新增能力

**GUI → 本地账号 → 「存档（本机账本）」页 → 账号等级（仅本机视图）**

| 元素 | 行为 |
|---|---|
| 当前档等级 | `当前：2 级（208 经验，距 3 级还差 142）· 账本 steam_…` —— 读本机账本，**引擎不跑也能看** |
| 目标等级 + 「设为该等级」 | 按等级表把等级换算成累计经验，写进本机账本的 `earned.experience`（原子写 + 覆盖前 `.bak`） |
| 「清除覆盖」 | 把账本经验置 0 ⇒ 合并后回到**服务端真实等级** |

**为什么这样就能生效**：引擎把本机账本的 `experience` 以 **max** 合并进 `/api/Progression` 响应
（`saves.apply_to_progression`），所以写更大的值下一次会话就能看到更高等级。
客户端**一局只拉一次** `/api/Progression` ⇒ **改完要重进游戏**。

## 边界（页面里也写着）

- **只写本机账本**，不写服务端任何数据；关掉代理后账号仍是真实等级。
- **只认已有账本**：没有账本时明确报错（`还没有本机账本（先让引擎跑一次、进一次游戏）`），
  绝不凭空造一份没有身份的空档（那会让引擎以为"这个玩家一切从零开始"）。
- 合并是 **max（只抬不降）**：把等级改**低**只影响账本值，服务端给得更高时仍以服务端为准。

## 需要你验一下

1. 打开 GUI → 本地账号 → 「存档（本机账本）」，看是否显示 `当前：X 级（Y 经验…）`；
2. 填目标等级（例如 10）→ 「设为该等级」→ 提示"重进游戏生效"；
3. **重进游戏**看账号等级是否变成 10 级、军械库里改装按钮是否在；
4. 再点「清除覆盖」→ 重进游戏，等级应回到真实值（测试号 2 级）。

> 如果你希望"改等级"顺带把经验也调到该级的**起始值以下**（例如刚好卡在 10 级门槛），
> 现在就是按等级表取该级起始累计经验（10 级 = 7,100），不会多给。

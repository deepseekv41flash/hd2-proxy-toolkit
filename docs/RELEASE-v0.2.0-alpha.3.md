# v0.2.0-alpha.3 — 「战况改写」页布局：三处小列表改下拉 + 选中表自适应行高（2026-11-17）

> **alpha 预览版 · 只动显示与交互**：版本位不变，`0.2.0-alpha.2` → `0.2.0-alpha.3`。

## 问题（用户反馈）

「战况改写」页有两处布局问题：

1. **变种词条 / 全局效果 / 星球词条** 各是一个只有 3 行高的列表 —— 只能看到 3 条候选，
   数量一多就要一直滚动，还占掉大量版面（变种 18 条、效果 312 条）。
2. **下方「选中…」表固定 2 行高** —— 实际生效 5 个变种时表里只露出 2 条，
   看起来像「只生效了 2 个」（用户报：「只能最多显示两个，但实际生效有 5 个」）。

## 本版改动

| 位置 | 原来 | 现在 |
|---|---|---|
| 变种词条 / 全局效果 / 星球词条 | 3 行高的可搜索列表 | **一行高的下拉选择器**（点开是原生下拉弹窗、带滚动条；可输入关键词实时过滤；右侧显示「共 N 条」/「命中/总数」） |
| 选中变种 / 全局效果 / 星球词条表 | 固定 2 行，超出只能滚动 | **按实际行数自适应**（2–8 行）：5 条就显示 5 条，清空后缩回 2 行 |

实现：新增通用控件 `PickDropdown`（`src/hd2proxy/gui/widgets.py`）；`RowEditor` 增加 `autosize` 选项。
下拉与「星球选择」的交互一致，键盘可用（回车取唯一命中、方向键浏览、Esc 关闭）。

## 验证

- GUI 实拍：变种下拉展开后完整列出 18 条（`虫族 7 · 掠食变种`、`虫族 7 · 孢裂变种` … 含阵营前缀），
  全局效果 / 星球词条显示「共 312 条」；三张选中表按行数增高；
- 单测 **394 → 399**：下拉持有全量条目、输入过滤与清空恢复、选中后回显 dual ids、
  5 行数据时三张表高度 5、清空后缩回 2。

# v0.6.0-alpha.1 — GUI「本地账号（仅本机视图）」：改名 + 存档 tab + 三条边界（2026-11-23）

> **功能版本**：`X.Y.Z` 变化（`0.5.5-alpha.1` → **`0.6.0-alpha.1`**）。

## 背景

到 `0.5.5-alpha.1`，存档线 G1–G6 已全部实现并做过实机验收。但 GUI 里缺一个"把本机账本讲清楚"的入口：
用户看到「物品与战备」会以为在改账号数据，而实际上**全部只在本机生效**。

这一版按用户拍板：**改名 + 存档 tab + 三条边界提示**。

## 页面改名

侧栏「物品与战备」→ **「本地账号」**，页头标题 **「本地账号（仅本机视图）」**，右上角标注"改名自「物品与战备」"。

页头固定三条边界（chips）：

| 边界 | 含义 |
|---|---|
| **仅本机视图** | 改的是客户端收到的响应，不写服务端任何数据 |
| **不回传服务器** | 本机账本不同步到任何服务器，也不影响同账号的其它机器 |
| **服务端仍是事实源** | 服务端给得更多就听它的；本机账本只在服务端给得更少（空号/私服/回档）时兜底 |

## 新增「存档（本机账本）」tab（第 7 个）

| 区域 | 内容 |
|---|---|
| 引擎状态一行 | `存档 <saveId> · 预绑定待校验 / 已校验 · 本局有写入`（与战况页顶部一致） |
| 摘要 | 档 saveId（来源）/ 身份来源 / 经验 / 成就 / 包进度 / 库存行 / 统计项 / 结算局数 / `catalog_build` |
| 按钮 | **存档预演**（后台跑 `save_preview.preview()`，弹只读窗口）/ 刷新摘要 / 打开存档目录 |
| 边界展开 | 三条边界在 tab 内再写一遍完整句子 |

截图：`research/screenshots/gui-inventory-tab6-存档（本机账本）.png`（GUI 冒烟实拍）。

## 实机验收结论（M5，已补档）

`docs/ACCEPTANCE-M4.md` 新增 M5 存档实机验收：

| 项 | 结果 | 证据 |
|---|---|---|
| ① 首屏识别 + 不混档 | ✅ | 首会话 `local→steam_…` **merged** + 归档；重启后 `activeSave=…（last）` 预绑定、`首屏按档渲染（来源 last）` |
| ② 结算入账 | ✅ | `MISSION +210 exp / 战备点×910 / 征用单×1`，与 `Mission/end` 逐字段一致；成就 4 条、统计 27 项 |
| ③ 重启后不回退 | ✅ | 无降级写入、无 TLS 错误、`inventory` 只抬不降 |
| ④ 换号不混档 | ⏳ 未实机（需第二账号） | 代码路径有单测（`switched`：整档回滚 + orphan 审计） |
